# Screen inventory

Build these screens in milestone order. Names are route/page names, not mockup OCR.

## Milestone 2 — shell

| Screen | Who | Purpose |
| --- | --- | --- |
| Parent login | Parent | Email/password or Google |
| Profile switcher | All | Avatar grid, optional PIN |
| PIN lock | Senior / parent | 4 digits |

## Milestone 3 — junior

| Screen | Purpose |
| --- | --- |
| Junior home | Stars, one goal bar, today’s missions |
| Mission complete | Camera / photo confirm, submit proof |

## Milestone 4 — senior

| Screen | Purpose |
| --- | --- |
| Senior dashboard | Accounts + work order list |
| Work order detail | Description, checklist, proof, thread |
| Senior phone console | Same data, stacked cards |

## Milestone 5 — parent

| Screen | Purpose |
| --- | --- |
| Parent console | Approval queue + manage work orders |
| Create work order | Title, category, stars, due, assignee or bounty, photo required, checklist |
| Rework note | Required comment when sending back |

## Milestone 6 — store

| Screen | Purpose |
| --- | --- |
| Marketplace grid | Category sections, redeem/need-more states |
| Parent fulfillment | Pending redemptions, Fulfill / Deliver |
| Parent inventory | Stock / cooldown / active toggles |

## Out of milestone scope (do not build yet)

- Family bulletins
- Custom external buy request form (SHP-03)
- Interest / streak / recurring routine UIs
- Multi-family or child-owned accounts
